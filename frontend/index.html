자사 브랜드 응답 (별도 집계)

브랜드명을 직접 물어본 프롬프트의 응답입니다. 언급률이 구조적으로 높을 수밖에 없어 위 SOV/취약/경쟁사 우위 집계에는 포함하지 않습니다.

브랜드별 감정 분포

이번 주 언급 건 기준 긍정/중립/부정 비율입니다 (언급이 없으면 표시하지 않음).

측정 방식: 코딩 에이전트 CLI 기반 근사 측정 (소비자 챗봇 노출도의 proxy) 이 서비스는 Claude Code CLI, Codex CLI, Gemini CLI 세 코딩 에이전트를 호출해 AI SOV를 측정합니다. 이 CLI들은 소비자용 채팅 제품이 아니라 코딩 에이전트이므로, 여기 수치는 실제 소비자 대화형 AI 노출도를 완전히 대체하지 못하는 근사치(proxy)입니다. Perplexity는 전용 CLI가 없어 측정에서 제외됩니다. 자세한 내용은 docs/metrics.md §7 참조.
